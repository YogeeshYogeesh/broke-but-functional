# Broke But Functional - Survive the Month

A personal finance app for Gen Z. Manage Rs 10,000 over 30 days and see how every decision changes your balance, daily allowance, forecast and risk.

Built with React + Vite.

## Run it

```
npm install
npm run dev
```

Then open the link shown in the terminal.

## Features (Submission 1)
- Rs 10,000 budget for 30 days
- Add income and expenses with categories
- Safe daily spending amount that updates automatically
- Month forecast, risk level and money health score
- Spending breakdown by category
- Day-by-day progress (move to the next day)
- Data saved in the browser
